# Antigravity Workspace Rules — Book Rating Platform

1. Read `GEMINI-PROJECT-CONTEXT.md` and `gemini-collaboration-handoff.md` before modifying code.
2. Never introduce ML, LLM calls, chat plugins, external AI accounts, or paid token usage.
3. Never add reading progress, reading status, or reading groups.
4. Keep backend rating and recommendation calculations authoritative.
5. After every vertical slice, update `gemini-collaboration-handoff.md` with Objective, Files changed, Database or API changes, Tests run and results, Known risks, and Follow-up work.
