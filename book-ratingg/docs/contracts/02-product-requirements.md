# Gemini Product Requirements
Implement these user flows:
- Browse or search for a book or series.
- View book score, rating count, authors, genres, series placement, reviews, and audiobook data when available.
- Submit or edit one overall rating from 1.0 to 10.0.
- Optionally select and score categories.
- Write a review, mark it as a spoiler, and comment on reviews.
- Follow users and add books to shelves.
- Receive local recommendations based on genres, rating history, popularity, and similar users.
- Unauthenticated users may browse public data but cannot create user content. Spoiler reviews must be hidden until explicitly revealed.
