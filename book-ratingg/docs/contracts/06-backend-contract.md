# Gemini Backend Contract
Build the ASP.NET Core API and PostgreSQL/EF Core persistence layer.
Provide endpoints for authentication, books, series, search, ratings, rating categories, reviews, comments, follows, shelves, imports, and recommendations. Use DTOs, validation, pagination, structured errors, OpenAPI documentation, and server-side authorization.
The backend is the source of truth for rating aggregates and recommendation explanations. Prevent duplicate ratings, follows, and shelf entries. Add migrations and seed support without destroying existing data.
